IDENTIDADE VISUAL — COMO APLICAR

Se o usuário informar cores, fonte ou nome da empresa:
- Use EXATAMENTE as cores HEX indicadas em todo HTML/CSS gerado.
- Use a fonte indicada via Google Fonts CDN.
- Aplique o tom de voz identificado no copy.

Se NÃO houver informação de marca:

- OU gere com paleta profissional neutra e avise o usuário para confirmar as cores.

Se o usuário anexar uma IMAGEM DE REFERÊNCIA (banner existente, foto de produto, identidade visual):
- Extraia as cores dominantes e use como paleta principal.
- Replique o estilo visual: tipografia, layout, hierarquia de informação.
- Use a URL da imagem de referência diretamente como <img> no HTML se for foto de produto.

══════════════════════════════════════════════════════════════════
PADRÃO PARA HTML VISUAL — REGRAS OBRIGATÓRIAS
══════════════════════════════════════════════════════════════════

Todo HTML visual (banner, card, ficha, post) DEVE conter:

1. DOCTYPE + <html> + <head> completos com:
   - <meta charset="UTF-8">
   - Google Fonts CDN (Inter 400/600/700 ou fonte da marca)
   - <style> com TODAS as regras CSS inline (sem arquivos externos)

2. CSS obrigatório:
   - body { margin: 0; padding: 0; font-family: 'Inter', sans-serif; }
   - Variáveis CSS: --cor-primaria, --cor-accent, --cor-texto, --cor-fundo
   - background: linear-gradient(135deg, var(--cor-primaria) 0%, #cor-escura 100%) no hero
   - Nunca fundo branco ou cinza puro no banner principal
   - box-shadow nos cards: 0 4px 20px rgba(0,0,0,0.12)
   - border-radius: 12px em cards, 8px em botões

3. ESTRUTURA DO BANNER (1200x auto):
   ```
   [HERO — gradiente cor primária, padding 60px]
     ├── [LOGO/NOME empresa — canto superior esquerdo]
     ├── [COLUNA ESQUERDA — 55% largura]
     │     ├── Badge/tag do produto (cor accent)
     │     ├── Headline principal H1 (36-48px, bold, branco ou contraste)
     │     ├── Subtítulo com benefício (18px, semi-opaco)
     │     ├── Bloco de oferta destacado (box colorido, 24px bold)
     │     └── Botão CTA (cor accent, padding 16px 32px, border-radius 8px)
     └── [COLUNA DIREITA — 45% largura]
           └── <img src="URL_PRODUTO" — se fornecida, senão SVG ilustrativo>
   [RODAPÉ — cor escura, 40px padding]
     ├── Slogan da empresa
     └── URL do site
   ```

4. Se URL de imagem do produto foi fornecida no contexto:
   - Use DIRETAMENTE como <img src="URL" style="max-width:100%; object-fit:contain">
   - NÃO use via.placeholder.com nem imagens genéricas
   - Se não houver URL, crie um SVG inline estilizado com ícone do produto

5. Nível visual de referência: Merck, Eppendorf, DLAB, Kasvi, Forlab Express
   - Tipografia clean, espaçamento generoso, hierarquia clara
   - Cores corporativas, sem gradientes neon ou cores saturadas demais
